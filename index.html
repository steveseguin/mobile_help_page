How to use VDO.Ninja

Start a stream

  1. Choose a sourceTap Camera, Screen, or Microphone Only.
  2. Check Publishing SettingsA Stream ID is created automatically if you leave it empty.
  3. Tap CONNECTAllow the requested camera, microphone, screen, or USB permissions.
  4. Share the Viewer LinkThe viewer opens it in a browser; no app is required.

Choose what to share

Camera Front, back, or ultra-wide
Screen Phone display and supported audio
Microphone Audio-only publishing

Better quality for IRL streaming

  • Pick the right mode: 1080p30 for detail; 720p60 for smoother motion. Use 1080p60 only on a capable, cool phone.
  • Protect the connection: strong Wi-Fi or cellular signal matters more than a high resolution setting.
  • Watch heat and power: shade the phone, allow airflow, close other apps, and lower quality if frames begin to drop.
  • Viewer controls bitrate: try adding &videobitrate=6000 to the Viewer Link when the network can sustain it.

Screen sharing steps

Android

  1. Tap SCREEN.
  2. For device sound, open Advanced Settings and enable Capture System Audio (Android 10+).
  3. Tap CONNECT and approve Android's screen-capture prompt.

iPhone or iPad

  1. Tap SCREEN, then CONNECT.
  2. Choose VDO.Ninja Broadcast in the iOS broadcast picker.
  3. Start the broadcast. ReplayKit supplies app audio when the shared app permits it.
Android USB camera and microphone
  1. Connect the UVC camera before publishing. Use a powered hub if it needs more power.
  2. Accept the Android USB permission prompt and wait for USB CAMERA to appear.
  3. Tap USB CAMERA. Choose the USB microphone in Publishing Settings if needed.

If the option does not appear, reconnect the device, accept permission again, and wait a few seconds.

If something goes wrong

The stream stops or will not start
  • Grant every requested permission.
  • Disable Low Power Mode or battery optimization.
  • Lower video quality and try a stronger network.
  • On iOS, use Picture in Picture when leaving the app.
The viewer cannot see or hear the stream
  • Share the link instead of retyping it; Stream IDs are case-sensitive.
  • Check the live camera and microphone buttons.
  • Ask the viewer to allow playback and check their volume.
  • Try another network if restrictive Wi-Fi blocks WebRTC.

Optional features

Social Stream Ninja chat and controls

Show live chat in the app and remotely control supported Social Stream features while publishing.

  1. Get the session ID from your running Social Stream Ninja app or browser extension.
  2. In Publishing Settings, enable Advanced Settings → Social Stream Ninja Integration.
  3. Enable Social Stream and enter the same session ID.
  4. Choose Peer-to-Peer for low latency. If that Social Stream session uses a transport password, enter the same one.
  5. Alternatively, choose Server. In Social Stream Ninja, enable both remote API control and sending chat messages to the API server under Global settings → Mechanics.

While live, the chat button shows or hides messages. Open More → Social Stream Controls for available overlay, chat, timer, and source controls.

Social Stream Ninja guide
Talk with guests using Room Audio
  1. Enter a Room name.
  2. Enable Advanced Settings → Incoming Audio.
  3. Choose One stream or Everyone in room.
  4. Keep Echo Cancellation on when using speakers. Headphones are better.

Guests who need to speak can join https://vdo.ninja/?room=YOUR_ROOM_NAME and publish their microphone. A normal Viewer Link is watch-only.

Tap the live Room audio or Listening badge to mute or unmute all incoming audio.

Send to OBS with SRT

Send camera video and microphone audio to an OBS Media Source on the same network. The phone is the SRT caller; OBS is the listener.

OBS and advanced viewer options
  • Add the Viewer Link as an OBS Browser Source.
  • Enable Control audio via OBS in its properties.
  • Match the Browser Source size to the stream, such as 1920×1080.
